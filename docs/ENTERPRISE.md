# 企业网盘与文档管理系统企业能力

## 领域覆盖

- **企业与团队空间**：按租户、组织、项目设置容量、负责人和数据边界
- **文件管理**：支持目录、上传、分片、秒传、预览、下载和回收站
- **版本协作**：保存版本、校验哈希、锁定、评论和历史恢复
- **精细权限**：支持继承、用户、部门、角色和最小权限控制
- **安全共享**：配置密码、有效期、下载限制、审批和撤销
- **水印与防泄漏**：按敏感级别应用预览水印、下载控制和告警
- **文档生命周期**：执行保留、归档、冻结、到期复核和合规删除
- **全文检索**：检索名称、标签、正文、所有者、版本和权限范围
- **访问审计**：记录上传、预览、下载、共享、授权和删除行为

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业网盘与文档管理系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `OBJECT_STORAGE`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
